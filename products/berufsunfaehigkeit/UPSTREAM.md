## Changed in phase 3

Phase 3 changes these files and adds these symlinks to take shared cells from the common core (`docs/core.md`). Each row states the file as it is now against upstream, the import commit `c23e22e`; how it got there is its history in git (`docs/core.md`, section "Changed files in `UPSTREAM.md`"). It removes the mortality file `mortality_table.csv`: the death rates come from the core's table factory.
