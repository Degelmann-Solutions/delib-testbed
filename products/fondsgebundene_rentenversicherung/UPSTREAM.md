## Changed in phase 3

Phase 3 changes these files and adds these symlinks to take shared cells from the common core (`docs/core.md`). Each row states the file as it is now against upstream, the import commit `c23e22e`; how it got there is its history in git (`docs/core.md`, section "Changed files in `UPSTREAM.md`"). Phase 3 adds two regular files: the tariff-type file `param_tariff_type.csv`, the product's scalar tariff parameters read by the core's `param`, and `prem_freq_table.csv`, the premium payment frequencies, which the code held as a literal set. It removes the mortality file `mort_table.csv`: the death rates come from the core's table factory. A changed or removed file keeps upstream's hash in the table above; `tests/test_provenance.py` skips its hash check. The added files and the symlinks are not copied files and have no hash.
